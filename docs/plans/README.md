# Plans

Implementation plans live here — one per feature:

```
docs/plans/YYYY-MM-DD-<feature>.md
```

A plan follows its spec, is written with `superpowers:writing-plans`, names the required sub-skill
in its header, and is referenced from the feature's `plan` field in `feature_list.json`. Keep this
directory at `docs/plans/`; the workflow deliberately does not use `docs/superpowers/`.
